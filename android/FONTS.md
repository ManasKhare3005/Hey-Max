# Bundled fonts

The app ships these typefaces in `app/src/main/res/font/` so the Appearance themes work offline.
All are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org) and come from
[Google Fonts](https://fonts.google.com):

| Theme | Display | Body |
|---|---|---|
| Classic | Instrument Serif | Manrope |
| Elegant | Fraunces | DM Sans |
| Editorial | DM Serif Display | DM Sans |
| Modern | Sora | Manrope |
| Geometric | Outfit | Outfit |
| Tech | Space Grotesk | Space Grotesk |
| Soft | Plus Jakarta Sans | Plus Jakarta Sans |
